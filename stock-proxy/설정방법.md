# 주식 시세 프록시 설정 (한 번만, 약 5분)

브라우저에서는 증권사·네이버 시세 API를 직접 부를 수 없어서,
내 구글 계정의 Apps Script가 대신 시세를 받아 가계부에 전달해요. 무료예요.

1. https://script.google.com 접속 → **새 프로젝트**
2. 기본 코드를 모두 지우고 `Code.gs` 내용을 붙여넣기 → 저장 (프로젝트 이름: 가계부 시세)
3. 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(톱니바퀴): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 권한 승인 (외부 서비스 접속 권한: 네이버 시세를 가져오는 데 필요)
   - "확인되지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)으로 이동**
5. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사
6. 가계부 앱 → ⚙︎ 설정 → **주식 시세 주소**에 붙여넣고 저장
   → "시세 주소 연결 확인 완료"가 뜨면 끝

## 종목 추가할 때 링크 붙여넣기
자산 추가 → 주식 → 검색칸에 증권 앱 링크를 붙여넣으면 종목명·티커·현재가가 자동으로 채워져요.
지원: 토스증권, 네이버 증권, 야후 파이낸스, 구글 파이낸스 링크 / 종목코드(005930) / 티커(AAPL)

## 참고
- 이 주소로는 종목 코드와 가격만 오가요. 가계부 기록·재산 금액은 폰 밖으로 나가지 않아요.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영돼요. (URL은 그대로)
- 시세는 네이버 증권 기준이에요. 국내는 실시간에 가깝고, 미국은 장 마감가 또는 지연 시세일 수 있어요.
- 환율(달러→원)은 프록시 없이 앱이 open.er-api.com에서 바로 받아와요.
